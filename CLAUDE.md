# Site Primo Pobre (canalprimopobre.com.br)

- Site estático: `index.html` (HTML + CSS + JS num arquivo só) e a pasta `img/`.
- Hospedado no Hostinger com deploy automático: todo push na branch `main` vai para o ar em segundos.
- Cores da marca: preto e amarelo (token `--gold` em `:root`). Fontes: Archivo (títulos) e Figtree (texto).
- O formulário de contato envia via FormSubmit para o e-mail do Eduardo.
- Fotos novas: redimensionar (máx. ~1000px) antes de colocar em `img/`.
- Textos do site são do próprio Eduardo: ao mudar, usar exatamente as palavras que ele mandar.

- SEO: título/descrição/Open Graph/JSON-LD no <head>; `robots.txt` e `sitemap.xml` na raiz (atualizar `lastmod` em mudanças grandes). Imagem de compartilhamento: `img/og-primopobre.jpg` (1200×630).
